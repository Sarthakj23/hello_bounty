# hello_bounty

A minimal repository for testing the OpenBounty bounty flow (claim, escrow, payout).

## The task

`hello.py` contains a stub `greet()` that raises `NotImplementedError`.
Make it return `"Hello, World!"` so that running the program prints:

```
Hello, World!
```

## Acceptance criteria

- `python hello.py` prints exactly `Hello, World!`
- `python -m unittest` passes
- No other files changed besides `hello.py`
